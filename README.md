# 📱 Smart QR Code Generator

A sleek and modern desktop application built in **Python** that instantly converts any text or URL into a fully functional, high-quality **QR Code**. 

## 🚀 Features
- **Instant QR Generation:** Converts links (`https://...`) or raw text into scan-able matrix barcodes.
- **Live Preview:** Displays the generated QR Code directly inside the custom GUI before saving.
- **Auto-Save Functionality:** Automatically saves the output as a `.png` file in the local directory.
- **Modern UI:** Built with a clean, dark-royal-purple theme using Tkinter.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **GUI Framework:** Tkinter
- **Core Engine:** qrcode
- **Image Processing:** Pillow (PIL)
